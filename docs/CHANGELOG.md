# 更新日志

## 2026-01-09

### 🆕 竖排文字支持

**新功能：**
- 自动检测竖排文字（`height > width × 1.2` 时自动标记）
- PPT 预览模式竖排渲染
- 编辑模式竖排文字预览
- PPTX 导出支持（使用 `eaVert` 东亚竖排格式）
- PDF/图片导出竖排渲染

**修改的文件：**
- `textbox.py` - 添加 `vertical` 属性
- `core/font_fit.py` - 竖排字号计算
- `editor_main.py` - 自动检测 + 预览渲染
- `features/export.py` - 导出支持

### 🐛 Bug 修复

- 修复调整检测框后坐标变为浮点数导致 OCR 识别报错的问题
